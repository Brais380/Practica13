# Practica13
Practica de programación en tinkercad con arduino comando (IF)
En esta practica utilizamos una practica anteriormente realizada para implementar el comando IF mediante un pulsador que debe bloquear el sistema (secuencia de encendido de pilotos); 
Segun el estado del pulsador debemos hacer que cuando se encuenter pulsado bloque el sistema inpidiendo su funcionamiento y si no esta presionado realizara la secuencia programada.
